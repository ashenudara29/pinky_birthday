🐼💕 PANDA VOICE AUDIO FILES DIRECTORY

assets/audio/

├── intro_surprise.mp3   (Plays during panda intro speech bubble)
├── question1.mp3        (Plays when Question 1 loads)
├── question2.mp3        (Plays when Question 2 loads)
├── question3.mp3        (Plays when Question 3 loads)
├── wrong1.mp3           (Plays when Q1 answer is incorrect)
├── wrong2.mp3           (Plays when Q2 answer is incorrect)
├── wrong3.mp3           (Plays when Q3 answer is incorrect)
├── correct1.mp3         (Plays when Q1 answer is correct)
├── correct2.mp3         (Plays when Q2 answer is correct)
├── correct3.mp3         (Plays when Q3 answer is correct)
└── all_correct.mp3      (Plays on final birthday unlock celebration!)

NOTE:
If any of these .mp3 voice files are not uploaded yet, the website automatically uses Web Speech API & audio synthesis fallbacks so the voice assistant ALWAYS works smoothly out of the box!
